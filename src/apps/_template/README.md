# _template

This is the starter template for new VibeZap micro-apps.

## Usage

```bash
# 1. Copy this folder
cp -r src/apps/_template src/apps/my-new-tool

# 2. Rename TemplateApp.jsx to your component name
mv src/apps/my-new-tool/TemplateApp.jsx src/apps/my-new-tool/MyNewTool.jsx

# 3. Update the component name inside the file
# 4. Follow the checklist in docs/micro-app-guide.md
```

See [docs/micro-app-guide.md](../../docs/micro-app-guide.md) for the full step-by-step guide.
